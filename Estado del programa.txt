Funcionamiento del programa:
    -Para ejecutar el programa, ahora mismo con ejecutar dando doble click en el programa de python llamado "program_impresora" bastaria para ejecutar todo lo que es la logica del programa, aparte de esto habria que ejecutar el programa "Launch Gis print server 2" para hacer funcionar el PMB.

    - Inicialmente hay que ir a la pestaña de movimientos y hacer un home, posteriormente al home ya se puede mover manualmente la mesa e incluso darle a iniciar impresión.

    - Para cargar la imagen primero habra que darle a load mode, con eso apareceran las configuraciones de dpi que se quieran escoger, una vez elegida la configuración al darle new image permitira escoger una imagen, finalmente para cargar la imagen en el PMB hay que darle a render y ya estar lista para iniciar la impresión.

    - En la pestaña de programa se pueden elegir tanto las velocidades como las posiciones de diferentes cosas como el inicio del curado, cantidad de pasadas etc.

    - En la pestaña de movimientos la velocidad, aceleración y deceleración unicamente configura el ir a posición objetivo.
