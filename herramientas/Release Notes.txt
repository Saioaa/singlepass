Atlas Machine Control Services Change Log
=========================================

Version 1.0.10 (2023-09-11) 
======================================

New features and bug fixes:

- Atlas Machine Control Services:
	[MCS-496]	WriteToFile job stores and print modes now add TIFF metadata for the resolution of the output images (in DPI)
	[MCS-585]	New feature: Over Print
				Print Modes now support Overprinting by using an Overprint Channel Mapping from Print Mode channels to output channels
	[MCS-586]	New feature: Single Pass Interleaved Print
				Print modes now support Interleaving in the Process (X) Direction by using an Interleave Channel Mapping from Print Mode channels to multiple interleaved output channels
	[MCS-877]	New feature: Atlas Server API to show if Atlas Server Licence is valid
				Added a new Atlas Server API: /api/licences
				Valid licence will:		Return 200, along with licence details
				Invalid licence will:	Return 404
	[MCS-1037]	New feature: BMP Job Store
				Added a BMP job store type for processing greyscale BMP bitmap image data with MIME type "image/bmp"
	[MCS-1161]	Atlas Server now uses ASP.NET 6.0 and is built using Visual Studio 2022. SDK users should install Visual Studio 2022 and ensure that the "ASP.NET and web development" workload is selected during the installation
	[MCS-1294]	Fixed some syntax errors in the Swagger file available at /swagger/AtlasServer/swagger.json
	[MCS-1351]	Atlas Server may now be used to configure the logging settings for HMBs
	[MCS-1353]	Atlas Server may now be used to collect log messages from HMBs and write them to disk. By default, any messages sent to Atlas Server via UDP on port 2020 will be logged
	[MCS-1384]	The default folder for Atlas Server log files has now been moved to C:\ProgramData\Global Inkjet Systems\AtlasServer
				The default folder for outputting image files has now been moved to C:\ProgramData\Global Inkjet Systems\AtlasServerOutput
	[MCS-1386]	Sub-pixel adjustment has been improved where mechanical nozzle offsets are not at perfect multiples of the pixel pitch from the first nozzle of the printhead and the printhead design supports this
	[MCS-1561]	New feature: High Quality Multipass Scanning Printing
				High quality multipass scanning printing is now supported, by configuring a ScanningStrategy value of "MultiPass".
				This may be used in conjunction with YResolutionMultiple values configured for high resolution in the cross-process direction
	[MCS-1565]	Added an ImageRepeat job store that can repeat images a specified number of times. This is helpful for some "loop printing" optimisations
	[MCS-1837]	Users can now specify a YResolutionMultiple value in Scanning Print modes, for higher resolutions in the cross-process Y direction
	[MCS-1962]	Added new Scanning Print Mode configuration properties "ImageHandling" and "Scanning Completion"
				"Image Handling" can be set to "PrintIndividually" which requests that successive images are fully printed before the next image restarts printing from the beginning of the increment cycle. 
				"ScanningCompletion" controls how many increments are required to "fully print" an image.
				ScanningCompletion defaults to "AfterImageHasPrinted", where the print finishes as soon as possible.
				Setting it to "AfterIncrementCycle" means that additional blank print regions may be generated to ensure that the print finished at the end of the increment cycle.
	[MCS-1969]	New feature: TestPattern Job Store
				Added a TestPattern job store type that can generate patterns for testing nozzles in the printhead array for printhead profiling purposes
	[MCS-1991]	Atlas Server now has better support for configuring HMBs. This includes fixing a bug that could lead to spurious configuration errors. Additionally, diagnostic reports are now generated if a configuration error does occur
	[MCS-2009]	Fixed a bug in PDF job store when mapping channel names to Spot colour names and the channel names differ from standard names like "Cyan", "Magenta", "Yellow", "Red". This is particularly likely to be significant for non-English deployments
	[MCS-2141]	HMB-SI-1536 now support up to 4bpp waveforms allowing up to 8 grey levels using 4bpp screened image data
	[MCS-2212]	New feature: High Quality MultiPass Scanning Print
				Overprinting with High-Quality Multipass scanning print modes can now be enabled via the Print Mode configuration property NumberOfPrintsPerPixel
	[MCS-2236]	New feature: Internal Encoder generated by SM-200
				Print Modes configured to use an internal encoder will now use an SM-200 or SEB-EPD to generate the encoder signal, rather than using the HMB directly
	[MCS-2288]	New feature: Micro-Weave Channel mapping
				Print modes can be configured to distribute colour channel data between 2 colour bars under the control of a MicroWeave Channel Mapping. Additionally, there is now support for adding more than one channel mapping. Hence, for example, it is now possible to use both MicroWeave and Overprint channel mappings in the same print mode.
	[MCS-2340]	The Print Mode specific file for describing nozzle compensation details has been renamed from "NozzleCompensations.csv" to "ScreenerRowCompensations.csv"
				Existing configurations that use "NozzleCompensations.csv" will still work as expected and the nozzle compensation information will automatically be written to the new file name "ScreenerRowCompensations.csv"
	[MCS-2352]	New feature: Composition Job Store
				The Composition Job Store allows foreground images to be composed over background images
	[MCS-2356]	New feature: Control of Scanning Increments
				Scanning Print modes can now specify the cross-process Y increment steps for the transport system.
				The steps are specified in pixels as an array of integer values. The configuration may contain any number of increments, including none. If the number of increments provided is fewer than the expected number for the scanning strategy then additional increments will be auto-calculated. If a specified increment is inconsistent with the scanning strategy then a valid value will be auto-calculated instead.
	[MCS-2394]	PDF jobs with multiple uncollated copies can now be optimised by generating Print Operations with a repeat count. To support this, job store image streams now handle information about repeat counts. Custom job stores written using the SDK should continue to work as before after recompilation. However, some of the image stream APIs that they use are now marked as obsolete. SDK users should follow the Intellisense obsolescence information to modify these.
	[MCS-2409]	New feature: WriteToFile Jobstores Metafile creation
				WriteToFile job stores can now write a meta file describing the names of the written image files and how they are arranged in frames.
				JdfTiffToFile job store can now use JDF metafiles to describe the names of the screened image files and how they are arranged in pages.
	[MCS-2413]	New feature: API to monitor HMB temperatures
				A new API has been added to get HMB and printhead temperatures: /api/Temperatures/HeadManagerBoards
	[MCS-2427]	HMB-SI-1536 waveform set voltage scale factors can now be configured. Print density across different printheads may be made more consistent by using this technique.
	[MCS-2428]	Fixed the configuration of the UDP log listener
	[MCS-2458]	Fixed bug whereby configuring SEB-EPDs could fail to configure when the associated HMB is reset
	[MCS-2459]	The Repeated Print Region loop print optimisation is now available when using ProductDetectThenContinuousRemovingWhitespace
	[MCS-2477]	Map files for static stitch, dynamic stitch, multipass and microweave can now be provided in BMP format as an alternative to TIFF, which was the only format previously supported.
	[MCS-2482]	SI-1536 waveforms may now have up to 20 segments and there is no longer a constraint that the last segment must be Low
